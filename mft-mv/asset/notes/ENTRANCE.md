> 冷开场第 11–12 镜（39.4 s → 第 0 小节 47.23 s）的新剧情。

## 一句话

人类从头到尾**只是一道影子**。两个守卫抢着去抓：01 先跑，02 翻摊子摔了个狗啃泥。侧台里一阵乱打，打斗以影子戏的形式投在幕布上。红心是整部黑白片里唯一的颜色，它从烟尘里蹦出来，被 02 一记全力投掷甩向舞台中央。红心在空中飞的时候，卓别林的唱片「发条松了」，越转越慢，放映机也跟着停住，只有红心照常在动。红心落地那一下就是第 0 小节：战斗框、颜色和 Spider Dance 同时出现。

## 声音：默片把声音还回来

主题（你定的）：**幽默、茶杯头、格斗游戏、弹幕射击贴原作，怎么夸张怎么来。**

- **第 1–10 镜还是默片**：只有卓别林，没有音效，说话靠字卡。这样「声音回来」才有对比。
- **从「当晚」起，声音一点点漏回来**：先是蟋蟀和脚步，人类把游戏的声音带进了默片。然后越来越吵，到红心落地那一下全部炸开。
- 用的全是游戏原版音效（`tools/import_sfx.py` 从 mtt-mv 的音效包里挑出来，剪到用得上的那一段）。分三类：
  - **似人音效**，角色「说话」用：
    - 怪物的文字音 `snd_txt2` 按音节一个个哔，靠变调分角色：01 高，02 低，玛菲特更高更快（「啊呼呼呼～」）。
    - Temmie 的 `snd_tem` 当观众小蜘蛛的叽叽喳喳。
    - `mus_sfx_oh` / `mus_sfx_ahh`、`mus_mt_yeah`、`snd_bluh`、`snd_hurtsmall` 当惊呼、喊叫、「耶！」、晕乎和「哎哟」。
    - Mettaton 节目里的观众欢呼 `mus_mett_cheer`。
  - **卡通**：滑哨 `snd_slidewhist`（往上弹）、套圈的包袱 `mus_rimshot`（Sans 的「咚哒——嚓」）、悲伤长号 `mus_wawa`、放屁坐垫 `mus_whoopee`（Sans 握手的梗）、平底锅 `mus_sfx_frypan`、鼓点 `snd_drumroll`、倒放的镲 `mus_cymbal`、「当当当——」`mus_dununnn`。

## 音乐过渡：留声机发条松了

- **不急停。** 卓别林一直放过 57–64 拍，这是这段最响的尾巴：赛跑、42.10 摔跤、43.47 撞头都踩在上面。44.88 它自己换进一段较轻的音乐，乐声变薄，刚好留给接住和蓄力。
- **出手那一拍（45.58）唱片的发条松了**：速度和音高一起往下沉，约 1.1 s 停住，就像 78 转唱片没劲了，最后带一点唱针沙沙声。1936 年那股轻快劲是被「拖垮」的，不是淡出去的，所以两种风格之间的落差不会显得突兀。
- 之后约 0.5 s 安静（顶点加坠落，只有哨音），落地那一下 Spider Dance 进来。缓冲还在：发条松掉的 1.1 s 加上 0.5 s 的静。
- **声画一起停**：放映机和留声机同时没劲，只有红心是实时的。这是从「电影」掉进「游戏」的那一刻。
- 时间不用动：`T.pre` 还是 47.15（第 0 小节 47.23），冷开场总长不变。`T.coldStop` 从 40.73 改到约 46.7（发条松完的时刻）。
- 实现：发条松掉的那段离线做成单独一段音频，用 Python 从 45.58 起按 1 → 0 的速率变速重采样，再加唱针噪声，作为一条音轨接在后面放。不在运行时做变调，导出视频时也稳定。
