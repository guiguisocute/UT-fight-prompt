# 音乐分析

> 恢复自 9c8453e:README.md「音乐分析」一节（b387838 精简文档时删除）。

`tools/analyze_music.py` 把 mp3（librosa）和 FLP（pyflp）合在一起分析，写入 `src/analysis.js`（`window.MV_ANALYSIS`，字段与前三部一致，另加 `score`、`motif`、`chords`、`leadOn`）。

### 这次多了一份「乐谱」

FLP 不是 Toby 的工程，是有人对着原曲做的逐轨复刻（工程里的采样路径是 `UnderTale Deconstruction\...`）。播放列表第 1 轨就是原曲 FLAC 本身（无伸缩，从 tick 0 开始），其余 24 个通道是对着它扒出来的：钢琴、钢弦吉他、小提琴、合唱、管钟、小号、锯齿波、NES 方波 / 三角波 / 琶音、断奏长笛、GM「Power」鼓组、正反两种吊镲 —— 共 **7486 个音符、12 个镲片音频块**。

- **对齐**：FL 写的是 300 BPM、PPQ 96 —— 一个 FL 小节 0.8 s；原曲的一小节（150 BPM）= 2 个 FL 小节 = 768 tick，一个 16 分音符 = 48 tick。196 个 FL 小节 × 0.8 s = 156.8 s，与 mp3 分毫不差。FLP 的鼓点落在音频起音通量的同一个相位上（11 ms，网格拟合 12 ms），整首的残差只在 11.2–13.8 ms 之间（漂移 < 3 ms）。所以 **乐谱时间 = 0.006 s + tick / 480**，可以当真值用。
- **音高**（扒谱的写法 ≠ 发声）：soundfont 通道带 −200 音分的通道音高 —— 谱面写在 G 小调，**发声是 F 小调**（前奏的音频色度最强的是 E♭ A♭ F B♭ C）。NES 的 VST 通道显示 0，实际差一个三全音（插件自己的调音）。逐通道把音符卷帘和音频色度做 12 种移调的相关：soundfont 各轨一律 −2，NES 各轨一律 ±6；八度看 CQT 能量 —— NES 低音两轨 +6，NES 高音三轨 −6（`tools/explore_transpose.py`）。`analysis.js` 里的音高一律是**发声音高**。
- **鼓**：「SGM-Power」是 GM 鼓组：C2 底鼓、G♯2 踩镲、A♯2 开镲、D2 / E2 军鼓（原声 / 电子）、D♯2 拍手、A3 吊镲、B5 铃。「Crash 01a」在采样器里开着 **reverse** —— 反向镲（吸气式上扬）。

### 方法与校验

- **速度**：起音包络上暴力搜索恒定 16 分网格：全曲 **150.00 BPM**，每个 20 s 窗口 149.98–150.01（只有 100–120 s 窗口拟合成 150.04：其中 96–115 s 是没有鼓的间奏）。
- **相位**（mtt-mv 踩过的坑：通量会把起音报晚 / 居中 STFT 会报早）：文件第一个起音（钢琴，从数字静音起）在波形上是 **6.0 ms**，第 12 小节全乐队砸入在小节线 +5.4 ms → **网格原点 0.006 s**。非居中短窗起音通量报 12 ms，晚了约 6 ms，与 mtt-neo-mv 的经验一致。
- **首拍**：FLP 的小节线（pattern 的摆放、底鼓的 0 位、吊镲）直接给出；第 12 小节鼓与全乐队砸入、第 60 小节的骤停、最后一个和弦在第 96 小节收住，都落在小节线上。
- **游戏里的循环**：录像里 BaaTH 在 **1:33.28** 响起，此后与 mp3 漂移 < 3 ms；放到第 96 小节（录像 4:06.9）后回到开头的钢琴前奏（前奏两小节一重复，相关只能定到前奏里）—— 录像里第 15 回合是在第二遍前奏上打的（`tools/explore_record.py`）。

### 节奏的 DNA：3-3-3-3-2-2 —— 「所有人的心跳」

动机的六下落在 16 分位 **0 3 6 9 12 14** —— 和 Power of NEO（mtt-neo-mv）是同一个切分型。前 60 小节它几乎每小节都在（钢琴 / NES / 管钟；B 段退到上方当固定音型），到间奏和 C 段才离开。

安黛因变身前说：「我能感受到他们的心脏，正随着共同的节奏律动。」—— 这首歌里那个「共同的节奏」，就是这六下。

### 这首曲子自己讲的故事

1. **前奏 12 小节没有鼓**：钢琴一个人，合唱和管钟慢慢加进来，第 11 小节低音三个一组往上爬、反向镲吸气 —— 第 12 小节鼓才砸下来。
2. **三道反向镲把全曲切开**：吸进 28、60、96 —— 每一次大转折之前都有 2.5 小节的吸气。
3. **大小调撞在一起**：全曲最响的 42、58 小节，小提琴一整小节停在 **A♮**（F 大调的三音），底下合唱压着 **A♭**（F 小调的三音）。C 段的小号在 77、89 小节也会落到 A♮。
4. **最响的那一刻之后就是最静的那一刻**：58 全曲最响，59 加花，60 的重拍上一切抽走，只剩钢琴（−10 dB）。
5. **间奏是 C 段的预告**：间奏钢琴弹的旋律，就是 72 小节起小号齐奏的旋律 —— 同一句话，先轻声说一遍，再吼出来。
6. **终局是四个 6 小节**：间奏是 6 + 6，C 段的伴奏 6 小节一循环（吊镲在 72 78 84 90）—— 不是常见的 4 / 8。
7. **结尾是个圈**：最后一个和弦在 96 的重拍收住；游戏里音乐回到开头的钢琴。

### 数据（`src/analysis.js`）

- 网格：`bpm` 150、`offset` 0.006、`sixteenth` 0.1、`barLength` 1.6、`bars` 98、`musicEnd` 96、`pattern` [0, 3, 6, 9, 12, 14]
- `sections`：上表 11 段（`part` 归为 intro / themeA / themeB / interlude / themeC / tail），带平均能量
- 逐 16 分（音频，局部归一化）：`slots.full / low / mid / high / kick / snare / hat / tone`；`slots.loud`（绝对响度，0 = −40 dB）
- 逐 16 分（乐谱）：`lead`（旋律的发声音高，MIDI，−1 = 无；旋律声部按段落：前奏钢琴 → A 钢琴八度 → B 小提琴 → 间奏钢琴 → C 小号）、`leadOn`（旋律起音）、`motif`（3-3-3-3-2-2 动机的起音）
- 逐拍：`bass`（最低的低音声部音，MIDI）、`chords`（模板匹配的和弦名，粗略：四五度堆叠让很多拍读成 sus）
- 60 fps 包络：`env.rms / low / high`
- **`score`**：`voices[名字] = [[16 分位, 长度(16 分), MIDI(发声), 力度], …]`，18 个声部；`drums[名字] = [[16 分位, 力度], …]`：kick / hat / openHat / snare / clap / crash / jingle，以及 `swell`（反向镲，第三项是长度）。16 分位 0 = 第 0 小节 = `offset`。
