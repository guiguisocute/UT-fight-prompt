# 第一部分 · 项目说明

## 1.1 一句话

> 「在创作了《UNDERTALE》之后，我为《DELTARUNE》设定的目标之一，就是让玩家最终能够挑战一个『真正的』Mettaton NEO，而不是一回合就结束的战斗。」—— Toby Fox（`asset/music/music-comment.md`）

这首《Power of "NEO"》未完成加长版，是那场「真正的战斗」的配乐，可战斗从来没被做出来。本片把它打完——**在天上打**。

屠杀线，核心尽头。**前奏里重演原作的那一回合**：查看、旁白、战斗，一击 966742。**音乐在第 8 小节真的掉进了寂静**（原作里音乐也在这一刻戛然而止），可被打中的只是一段重播。第 9 小节噪声升起，真正的镁塔顿 NEO 从天而降；第 10 小节，**他一拳砸碎了舞台的地板——地板下面是核心无尽的深处：一片虚拟的科技海，他管它叫「天空」**。一场在无尽下落的「天空」里打的空战：心是一架黄色的小战机，他变形成一架粉色的战机。他是为了身后那些正在撤离的人而战。最后，他把整片「天空」都打了出去；在这首未完成的曲子**永远到不了的那个重拍**上，他最后一炮落了空——差一根线，他没电了。刀在之后的寂静里落下。

## 1.2 立意（贯穿全片的四个身份）

- **明星**：他把这场必输的战斗变成他这辈子最好的一场演出，全程直播（角落里的 ●REC、机位名 CAM 1 / CAM 2 / CAM 3）。
- **守护者**：每多撑一秒，身后撤离的人就多走一步。他不需要赢，只需要拖住你——直到远处最后一部电梯关上门。镜头让观众看见心看不见的东西：他每次出手后余光都扫向身后。
- **兵器**：「一开始我是作为杀人机器诞生的。」——光束、光剑、浮游炮、光之翼、超频（TRANS-AM），还有**变形**。
- **偶像**：地底的怪物从没见过天空。他用核心的电力给观众造了一片「天空」——然后把它也打出去。

## 1.3 成片规格与时间轴

- 1920×1080、60 fps；2D 世界 960×540（原作 640×480 布局居中）；三维“天空”按美术像素 480×270 渲染再放大（色阶化 + Bayer 抖动）。
- `T.pre = 28`（序幕，静默）；第 b 小节 = **28.029 + 1.6552·b** 秒；`T.dur = T.pre + 162.24`；`T.tail = 17.2`（尾声，静默）；全片约 207.4 s。
- 结构：序幕 0–28 s（静默）· 一 彩排 28–44.6 s（0–9 小节）· 二 正式直播 44.6–177.0 s（10–89）· 三 最后的射击 177.0–190.2 s（90–97）· 尾声 190.2–207.4 s（静默）。

## 1.5 关键常量

**音乐**（librosa；音序器做的样带，网格严丝合缝）：

| 项目 | 值 |
| --- | --- |
| 速度 | **145 BPM 全曲恒定**，16 分 = 0.10345 s，一拍 0.4138 s，一小节 1.6552 s |
| 首拍 | **0.029 s**（居中 STFT 会把起音报早 20–40 ms，用非居中短窗起音通量 − 半 hop，回溯早 8 ms） |
| 长度 | 162.24 s = 98 小节 |
| 调性 | 前奏与尾声以 C♯ 为中心；主体在 D♯（D♯ 弗里几亚、E 自然音，冷硬的机械感；低音 D♯1 39 Hz 持续音，CQT 要下探到 A0 才看得出）；吉他段 G、G♯ 更多更亮 |
| 曲式 | 前奏 0–7（游戏里那段，C♯2 低音，3-3-3-3-4 重音）· **8 骤停**（一拍内掉到 −41 dB）· 9 上扬（8.6 起白噪声 −38→−21 dB，9.14–15 军鼓装饰）· A 10–17（D♯1 脉动低音，军鼓 3-3-3-3-2-2，反拍开镲）· B 18–33（更暗、抒情 E 大调旋律；18/26 开头相同；**33 噪声上扬**）· C 34–41（旋律在 B5–C♯6 与 D♯4–F♯4 之间两个八度来回大跳；34–37 = 38–41）· A 42–49 · B 50–65（**65 噪声上扬**）· 吉他 66–81（推弦滑音，灵感 Brandish《Ending 2》；每小节第 3–4 拍低音半音上推，偶数小节 G–G♯、奇数 F–F♯；**81 噪声上扬**）· C 82–89（**89 鼓加花**）· 尾声 90–97（鼓、超低音、镲全部抽走，拨弦压在 A–B–C♯ 上）· **98 硬切**（最后重音在 97.14，下一个重拍永远没有来） |

**曲子的结构就是这场战斗**：前奏 = 原作那一回合；第 8 小节骤停 = 原作那一击；9 上扬、10 砸下 = 「不止一回合」；首尾同一个 C♯ 与 A–B–C♯ 低音（原作的回合和最后的回合同一个调）；没写完的结尾 = 最后一击（那个永远没来的重拍就是他的最后一炮：落空，MISS，音乐消失）。

**规则**：
- 玩家 **FRISK**（录像里叫 FLOWER，本片 HUD 用 FRISK 大写），**LV 15，HP 76 / 76**，武器**真刀**（一条攻击条、正中命中、一道红色斩痕），防具刮花的眼镜，击杀 103。
- 心：0–9 原作红心；**12 起是黄心 = 战机**（黄心本来就只能朝心尖射击）；90 起回到原作战斗画面的红心。
- **防御 9**：他被碰到一下就结束——**他的身体全程不被任何东西碰到，直到第 98 小节后的那一刀**。心的子弹只打掉他的**武装**：诱饵炸弹、浮游炮、护盾、导弹、光剑臂、双腿。
- **心只受伤三次**：42（X 字斩，76 → 52）、80（零距离炮，52 → 34）、86–89（整片「天空」的电力，34 → **1**）；其余一律擦身而过（擦弹迸火花，`check.cjs` 校验，三维的光束/浮游炮/导弹也算：线段到球的距离）。
- **心一直在自动开火**（看得见的黄色曳光弹 `H3.autoFire`），但永远打不中他：弹流追上他的那一刻他已经闪开（两帧），子弹穿过残像——灰色 MISS（体现“高速无能为力”）。他闪开时偏好不往镜头这边闪。
- 原作颜色规则：蓝色的光只在心不做机动时穿过，橙色只在心做机动时穿过；白色攻击从不碰心。
- **他的状态是电量，不是 HP**（`battery.js`）：片头名牌下面就是他的电池（「电量 ⚡」，16 格一格一个 16 分充满到 100%），之后挂在他头顶；飞着就在掉，战机形态 ×2（»» x2），TRANS-AM ×7、变红、变成七段数字倒计时（EVA「活动限界」M:SS:CC），57 吃一口闪电，82–85 借全地下世界的电力充爆（百分比冲到几千、溢光），86–89 光束把它和心的 HP 一起烧掉、**同时停在 1**，97.13 最后一格熄灭（0%，打 ✕）。敌方 HP 条只在最后一刀出现一次。
- 叙事只用 UT 自己的通道：文本框旁白、他的气泡、数字、按钮。**不打别家游戏的界面文字**（不出现 WARNING / READY / TRANS-AM 英文），唯一例外是 74.10–78.12 座舱里的 EVA 式中文警报。不分屏。
- 新台词口吻按原作镁塔顿：「亲爱的」、电视术语（彩排、特写、镜头、第二幕、压轴戏）、短句。

**武装的递减（全片看得见的“血条”）**：完整（光之翼 + 光剑臂 + 炮臂 + 双腿）→ 26 光之翼六个尖角裂成 **6** 枚浮游炮 → 30–31 击落 2 枚（**4**）→ 33 四枚拼成金字塔护盾 → 42 四枚再裂成 **12** 枚 → 49 一发蓄力弹贯穿 4 枚（**8**）→ 52–56 数据风暴里全部击落（**0**），翅膀只剩纯粹的光 → 58–61 导弹打光 → 66 TRANS-AM → 79 光剑臂被蓄力弹击碎 → 81 超频过载、双腿炸飞（再也不能变形）→ 82–89 只剩躯干与炮臂 → 尾声断臂残躯举炮向上。

## 1.6 本片专属技术要点

- **2D**（序幕、彩排、HUD、文字）：五张平面（核心远墙、柱子、他、战斗、最近景）被真 3D 相机拍；在「家」时与原作逐像素一致。
- **科技海**（`gl3d.js` + `sky.js`，WebGL 2）：全屏光线步进——体积数据雾（预生成 3D 噪声纹理 + 雾层轮廓，被下方核心的光照亮，表面浮着全息网格）、按深度叠加的残缺光之网格（电路板）与反应堆粉色光环、核心的光、数据星、远处的网格海、向上流的数据光条；按 480×270 美术像素渲染、分色阶、Bayer 抖动。灯光程序 `TL.sky` 关键帧插值：核心冷蓝（10–17）→ 数据峡谷深蓝（18–33）→ 粉色舞台光（34–41）→ 紫（42–49）→ 红黑数据风暴（50–61）→ 风暴之上寂静的白色数据星（62–65）→ TRANS-AM 红（66–81）→ 熄灭（82–85）。**暗场景为主**，亮的只有光。
- **体素**（`vox.js`）：精灵每个像素挤出成体素柱（厚度 = 到轮廓的距离场开方），只生成露在外面的面；正面是原作像素，背面黑底白边；按面法线 2–3 级色阶光照。心 = 像素心挤出厚度（横滚时看得见翻面）。他的人偶关节拆成大腿/小腿、上臂/前臂，翼可张收扇动，头可转。
- **变形**（人形 ↔ 半变形 GERWALK ↔ 战机，《超时空要塞》VF-1 三段变形 + Z 高达 Waverider）：双腿 → 两个发动机舱、尖脚 → 喷口；双臂收到机腹下、炮臂成机首下方的炮、刃臂成腹鳍；头缩进胸口；胸口心核 → 粉色心形座舱盖；光之翼 → 后掠主翼；双肩的角 → 鸭翼。零件按四元数逐个插值，**一块零件一个 16 分，「咔、咔、咔」，最后一声「锁定」**。人形为主，战机只在需要速度时（18–25、32–33、49–61 的大部分）。
- **光之翼**：翅膀本体发白光，外面一层用翅膀形状距离场驱动、沿放射方向流动闪烁的粉色光焰；撒四角星光点，高速拖成光带；心核与眼睛也是光源；浮游炮全灭后（62 起）光焰更大；TRANS-AM 变红。
- **三维武器**（`arms3.js`）：`H3.autoFire`（心的曳光弹）、`H3.lance`（有预兆有分量的光束：开火的那个东西转过来、发白发烫、光点被吸进炮口、一圈光环收紧；整条路线先亮细线 + 一条光束宽的淡光带、越到最后闪得越快；开火时整条光束一下子出现、比之后宽一半、白芯粉身光晕、炮口冲击波、后坐；撑住再像 Gaster Blaster 一样收窄熄灭）、浮游炮、光剑、刀光、光墙、迷你镁塔顿导弹 `H3.minis` / `H3.circus`、光刃 `H3.crescent`。
- **HUD**（`hud.js`，心的第一人称，黄色，原作字体）：心形准星、俯仰梯与航向刻度、一直往下跳的高度表（跳到 0 从头再来 = 无尽下落）、目标框（框住他与浮游炮，下面距离，上面他的电池）、**被锁定 = 他的摄像机对焦框**（粉色四角从画面四角向中间收拢、哔声越来越急）、下方「FRISK LV 15 HP 76 / 76」。座舱镜头里**不画心自己**。
- **EVA 式警报**（`eva.js`，只在 74.10–78.12）：他从哪边来，那边就盖上一簇红橙六边形「警告」（画外/身后时多一个箭头）；右边一串错误窗口层层弹出（目标丢失、无法锁定、目标速度超出上限、姿态异常、机体过载 9.4G、弹道计算失败、推进器过热、接近警报、碰撞警报，带编号）；最重的三下一条横贯画面的橙色警报带（警告 / 危险 / 紧急 / 接近，黑橙斜纹镶边）；画面四周红光脉动；每一下擦过 HUD 被震歪几像素；目标框找不到他、乱跳「???」。大字用 20×20 粗黑体点阵（`MV_HEAVY_GLYPHS`），小字宋体，数字原作 HUD 字体。
- **QTE**（`qte.js`，“游玩感”）：PS 四键（×○□△ 各自颜色）与左摇杆，画成原作 UI 像素风（白描圆环、黑底、2 倍像素）；按下那拍变黄 + 光圈 +「叮」；按住是一圈慢慢填满的环；连打是按钮一下下跳 + 下面一条原作 HP 红黄配色计量条；来不及的被红 ✕ 划掉。提示在心的右上方。**锁定** `H3.soulLock`：心瞄上浮游炮时黄色菱形套上去、一声哔收一格，锁死时外面再套一个转着的菱形、心和目标间一条虚线，击落时原地一个黄色 ✕。
- **合成音效**（`synth.js`）：坠落的风、喷气轰鸣、音爆、变形的「咔」、掠过的呼啸（多普勒）、锁定警报、雷声。
- **镜头工具**：`tools/cutaudit.cjs`（每个剪辑点前后量：主体在画面里的位置、摄影机在两人连线哪一侧、追逐的屏幕方向、视角转角）+ `tools/cutsheet.py`（切前切后帧对照表）+ `tools/camcheck.cjs`（镜头内速度/转向跳变）。
- 坐标系按真实速度曲线烘焙（`TL.vel`）；两人路线是关键帧间 Hermite 样条；姿态（俯冲、空翻、横滚、拉起）按 240 Hz 烘焙成四元数。
- 尾声“画面停住”是一段把画面时间钉死的 `TL.remap`，后期的故障切片时钟也改用画面时间（`TL.post.hold`）。

# 第二部分 · 通用框架要求（六个 MV 共用，必须照做）

> 这六部 MV 原本是同一套自研「无状态时间轴 + 像素画布 + WebGL 后期 + 无头浏览器逐帧导出」框架，一部一部迭代出来的。复刻时**先把这套框架搭起来并验证**，再碰任何分镜。

## 2.1 技术栈与目录

- **纯静态网页**：一个 `index.html` 按顺序 `<script src="src/xxx.js">` 加载所有模块；**不用打包器、不用前端框架、运行时零 npm 依赖**。全局命名空间 `window.MV`，每个文件是一个 IIFE，往 `MV` 上挂东西。
- 画布 `<canvas id="mv" width="1920" height="1080">`；**世界坐标 960×540**（原作 640×480 的战斗布局 1:1 居中，左右多出来的地方留给运镜和特效），像素世界按 2 倍放大到 1080p。角色精灵 2 倍像素、心和弹幕 1 倍像素——**和原作一样的混合分辨率**，不要把所有东西统一缩放。
- 2D 用 Canvas2D（`imageSmoothingEnabled = false`，坐标一律 `Math.round`），后期和 3D 用 WebGL（自己写一个 `m3.js` 小矩阵库，不引入 three.js）。
- Node.js（≥18）+ Playwright（Chromium）+ ffmpeg 只用在 `tools/` 的离线脚本里；Python（numpy / scipy / librosa / pillow）只用在分析与素材打包脚本里。

推荐目录（与原工程一致）：

```

src/analysis.js       音乐分析结果（tools/analyze_music.py 生成，勿手改）

src/glyphs.js         中文点阵字形（tools/make_font.py 生成，勿手改）
src/util.js           数学、缓动、确定性随机、音乐时间 T.*
src/engine.js         Track / Steps / TL 事件仓库 / 冲击 / 粒子
src/sprites.js        精灵与字体绘制
src/draw.js           像素绘图原语（像素圆环、像素线、文字框……）
```

## 2.2 核心原则：一切都是时间 t 的纯函数

- 任何一帧都必须能**单独**渲染出来：实时播放、拖动进度条、逐帧导出、倒带（VHS 回放）、慢动作，全部走同一套代码。
- **禁止** `Math.random()`、禁止跨帧累积状态（“上一帧的位置 + 速度”）。随机一律用基于哈希 / 种子的确定性函数：`U.hash(x)`、`U.hash2(x,y)`、`U.noise(x)`、`U.rng(seed)`（mulberry 类）。
- 物理（重力心、蓝心砸墙、风推心）要么写成解析式，要么**预先离线模拟后烘焙成采样**（`Track.bake(t0, dt, {x:[...], y:[...]})`），播放时只插值。
- 引擎 API（建议照抄这套语义）：
  - `new MV.Track(init)`：多通道关键帧轨道。`.to(t0, t1, vals, ease)`、`.set(t, vals)`、`.hop(t0, t1, vals, h)`（抛物线跳）、`.bake(...)`、`.at(t)` 返回该时刻全部通道值。段与段从“上一段到达的值”混到目标值。
  - `new MV.Steps(v)`：分段常量（姿态、模式、开关），`.set(t, v)`、`.at(t)`、`.since(t)`（当前值已持续多久）。
  - `TL.add({t0, t1, z, draw(ctx, emi, t, S), hit?(t, x, y)})`：一个“活在 [t0,t1) 的可绘制事件”。按 z 排序绘制。`TL.active(t)` 用二分找出当前活着的事件。会伤人的弹幕必须实现 `hit(t, x, y)`（该时刻点 (x,y) 是否在弹幕里），页面暴露 `MV.checkHits(t0, t1)` 给 check.cjs 用。
  - `TL.impact(t, {amp, dx, dy, zoom, rot, inv, bw, flash, ca, dur})`：冲击——震屏（方向踢 + 随机抖）、推镜、旋转、反相帧、黑白帧、闪白、色差，全部随时间指数衰减，由 `TL.fxAt(t)` 汇总。
  - `TL.glitch(t0, t1, amt)`、`TL.shock(t, {...})`（屏幕冲击波）、`TL.burst(t0, {...})`（解析式粒子爆发，无模拟状态）、`TL.ring(...)`（像素圆环）。
  - 时间重映射：`TL.remap(t0, t1, f)`（画面显示 f(t) 而不是 t，用于 VHS 倒带）、`TL.hitStop(t, hold, catchUp)`（顿帧后用 Hermite 曲线追回音乐，无跳变）、`TL.slowmo(t, W, a)`（先慢后快、首尾速率为 1 的慢动作）。**音乐永远不停，只有画面时间被重映射**。
  - 音效表：`TL.sfx.push({t, name, vol, rate, end, fade})`，播放器用 WebAudio 提前 0.25 s 排程，导出时由 render.cjs 混进音轨——两边读同一张表。
- 每个 `draw(ctx, emi, t)` 都拿到两张画布：`ctx` 是颜色层，`emi` 是**自发光层**（辉光的来源）。会发光的东西（光炮、魔法、眼睛、火）要同时往 `emi` 画。

## 2.3 音乐网格（卡点的唯一依据）

- `tools/analyze_music.py`（librosa）分析音乐，写出 `src/analysis.js`：`window.MV_ANALYSIS = { bpm, offset(第 0 小节第 0 拍的秒数), sixteenth, barLength, duration, bars, slots:{kick, snare, tone, full}(每个 16 分音符格子的实测起音强度 0–1), env:{rms,...}(包络), envFps, sections:[{bar0, bar1, name}] }`。
- 先用 `beat_track` 粗估 BPM，再**用 16 个相位逐一和主节奏型做相关**挑出真正的第一拍；检查全曲是否恒速（游戏原曲通常是恒速的，同人混音/未完成版要分段核对）。
- `util.js` 里提供 `T.at(bar, beat=0, s16=0)`（小节/拍/16 分 → 视频秒，允许小数、溢出、负数）、`T.slot(t)`、`T.barOf(t)`、`T.acc(slot, band)`、`T.env(t, band)`、`T.pulse(t, period)`、`T.accPulse(t, band)`、`T.section(t)`。
- **所有事件都写成 `T.at(...)`**，不允许出现手写的“37.42 秒”。
- 卡点约定：弹幕在音符**上**到达最长 / 命中；炮在拍上开火；心的闪避在**前一个八分音符**完成；镜头硬切落在重拍；震动强度、粒子数量可以读该 16 分格的实测强度 `T.acc`。
- 冷开场、多首曲子拼接时，`T.pre` / `T.off` 等偏移写在 util.js 一处，`MV.MUSIC = [{src, t0, dur, off}]` 列出每个音频文件在视频时间轴上的起点（`src` 是相对 `index.html` 的路径，本仓库里是 `asset/music/…`）；播放器和导出都读它。

## 2.4 素材管线

- `tools/import_assets.py`：把 `asset/` 里的精灵表切片（按 spriters-resource 表格的格子或手工坐标）、透明化、去背景，原作音效 wav/ogg 用 ffmpeg 转 mp3，统统打成 `src/assets.js`：`window.MV_ASSETS = { img:{name: dataURI}, sfx:{name: dataURI}, meta:{锚点/帧表} }`。**这样双击 index.html（file://）也能跑，没有 CORS 问题。**
- 战斗 UI（心、四个按钮、HP/KR、攻击靶、斩击、对话气泡、字体、菜单音效）统一用 `asset/ui-kit-c2-sans-fight/`（原作素材，带锚点 meta.json）。
- 中文：`tools/make_font.py` 扫描 `src/*.js` 里用到的所有非 ASCII 字符，用 16 px 宋体（`C:/Windows/Fonts/simsun.ttc`，或 GNU Unifont）渲染成 1-bit 点阵，写进 `src/glyphs.js`；画面上所有中文都是点阵字，和原作中文版的观感一致。英文/数字用原作位图字体。
- 角色动作：优先用原作精灵帧；需要原作没有的动作时，**把精灵切成部件做骨骼 rig**（关节点手工标定，或在录像里逐帧拟合），而不是重画一个风格不同的角色。
- 生成文件（analysis.js / assets.js / glyphs.js）**永远不手改**，改脚本重新生成。

## 2.5 渲染层次与后期（post.js）

- 每帧：`scene.render(t)` → 求值所有 Track / Steps → 在离屏的**世界画布**（960×540 + 四周留边，供运镜不露边）上画背景 → 弹幕 → 角色 → 战斗框/HUD；同时画**发光层**；再画不受相机影响的**屏幕层**（字幕、遮幅、读档界面等）。
- `post.js`（WebGL）：把世界画布当作 3D 空间中的一张平面，用**真的 3D 透视相机**去拍（pitch / yaw / roll / dolly / 平移），远处可有一层视差虚空网格；然后依次叠加：双层辉光（emi 层）、径向色差、黑白反相冲击帧、黑白阈值帧、故障切片 / RGB 撕裂、甩镜运动模糊、VHS（倒带时）、点阵网格 / 扫描线、暗角、胶片颗粒。
- 镜头语言要“现代”但画面要“原作”：**像素永远是方的、不糊**（后期在 1080p 上做，世界层最近邻放大）。

## 2.6 播放器（main.js / index.html）

- 空格 / Z / 回车：播放暂停；← →：±2 s（按住 Shift：±1 小节）；D：调试信息（`t / 小节 / 拍 / 16 分 / 段落名`）；H：干净画面（隐藏 UI，截图用）；点击底部进度条跳转。
- URL 参数：`?t=64`（从 64 秒开始）、`?lat=0.03`（音画延迟校准）、`?lab=<name>`（样片）、`?render=1&w=1920&h=1080`（导出模式：只暴露 `MV.exportFrame(t)` 和 `MV.ready`）、`?clean`。
- 音乐用 `<audio>` 元素按 `MV.MUSIC` 的偏移播放并以它为时钟；音效用 WebAudio 解码后按 `TL.sfx` 排程。第一次按播放要等音效全部解码完再开始。

## 2.7 工具（tools/）

> 本项目的 `tools/` 已经附上原工程的全部脚本（路径改成了本仓库布局），**先读 `tools/README.md`**。下表是通用的那几样；各项目专属的检查工具（例如 mft 的 `beatcheck.cjs`、mtt-neo 的 `cutaudit.cjs` / `camcheck.cjs`）也在里面。可以直接用，也可以照着重写，但页面要先提供它们用到的接口（`MV.ready`、`MV.exportFrame`、`MV.checkHits` 等）。

| 脚本 | 作用 |
| --- | --- |
| `serve.cjs` | 无缓存静态服务器（预览 `http://localhost:4173`） |
| `pw.cjs` | 解析 Playwright；页面一律用 `file:///…/index.html?…` 打开并加 `--allow-file-access-from-files`；`--gpu` 时 `--use-angle=d3d11 --ignore-gpu-blocklist --enable-gpu-rasterization`，否则 `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` |
| `frames.cjs <outDir> <t...> [--gpu --w --h --lab]` | 渲染指定时刻的静帧（**最常用的检查手段**） |

| `sheet.py` / `contact_sheet.py` | 把一串静帧拼成联系表（contact sheet），一眼看完一段 |

| `eval.cjs` | 在页面里执行一段 JS 打印结果（查某时刻某轨道的值） |

导出规格：**1920×1080、60 fps、H.264（NVENC：`-preset p5 -rc vbr -cq 19 -b:v 0`；或 libx264 `-crf 20 -tune animation`）、yuv420p、AAC 320k**。不加 `--gpu` 用 SwiftShader 也能跑，只是很慢。

## 2.8 画面与叙事的共同约束

- **原作 UI 本地化风格**：战斗框、HUD（名字 / LV / HP 条 / KR）、四个按钮、打字机文本（`* ` 开头、逐字出现带打字音）全部按原作像素位置与比例；中文文案参考原作官方中文。
- 弹幕命中与否必须“说得通”：心被打中 → 红闪 + 受伤音 + HP 真的掉；没写命中的地方，弹幕**绝不**碰到心（check.cjs 验证）。
- 原作没有的演出（3D 运镜、第一人称、2D→3D 切换、打破第四面墙）都要能从原作战斗机制里**长出来**：先用原作的语言立住规则，再打破它。
- 所有对白、旁白、字幕先写进剧本表（小节·16 分 → 文本 → 说话人 → 打字速度），再进代码。

# 第三部分 · 工作方式（最重要：逐步推进，切勿一次成片）

> ⚠️ **再说一遍：不要试图一次性写完整部 MV 再导出看效果。** 原作每一部都是几十轮“做一小段 → 出静帧 → 出小样 → 对照原作和剧本挑毛病 → 改”迭代出来的。一次成片的结果一定是：节奏全错位、弹幕穿心、镜头乱跳、角色走样，而且错误叠在一起无从下手。

## 3.1 必须遵守的推进节奏

1. **阶段 0 · 读与看（不写代码）**
   - 把本 PROMPT 从头读到尾，列出 `asset/` 里每个文件是什么、会用在哪一段。
   - 用 ffmpeg 从 `asset/record/` 的原作录像里抽帧（例如每 0.5 s 一张，再拼联系表），对照本文的分镜逐段看懂原作的 UI 位置、弹幕形态、角色动作、文字内容。把观察写进 `work/notes.md`。
   - 输出：素材清单 + 你理解的分段表（小节范围 → 内容），**先给用户确认**。
2. **阶段 1 · 框架骨架**
   - 搭 `index.html` / util / engine / main / scene / post / serve / frames / render / check。
   - 跑音乐分析，**验证网格**：做一个“节拍器样片”（每拍闪一次、每小节第一拍大闪、屏幕角落显示小节号），导出 20–30 秒带声音的小样，**亲自核对**画面闪光和听到的鼓点是否对齐（误差 < 1 帧）。网格不对，后面全部白做。
   - 输出：节拍器小样 + `analysis.js` 的关键数字（BPM、offset、总小节数、段落表）。
3. **阶段 2 · 素材入库**
   - 切精灵、打包 assets.js、生成字形；做一张“素材总览”静帧（所有精灵、所有动画帧、所有字体一字排开），检查透明边、锚点、尺寸是否正确。
   - 搭原作战斗场景的**静态还原**：一帧和原作录像截图并排对比，UI 像素位置对上为止。

## 4.0 镜头与剪辑的规矩（先读，全片适用）

> 用户原话：「现在已完成部分的镜头衔接有点不太连贯，对观众而言有点太花」；「有一些神秘分镜（就是不知道想表达什么的镜头）」；「浮游炮的网格切分穿过那里的镜头一直在抽搐」。

1. **一个乐句一个镜头想法**：剪辑点落在乐句或重音上；除刻意的蒙太奇外，一个镜头不短于 1 小节。
2. **不跳切**：前后两个镜头角度差 < 30°、景别也差不多时就不剪；机位要挪就在镜头里运动过去。
3. **轴线**：一段戏里摄影机待在两人连线的同一侧。12–17 的对射他在左、心在右；数据峡谷一律「向右飞」；领先的一方在右边。越轴只能让观众在镜头里看着它发生，或用正面/背面的中性镜头过渡。
4. **视线追踪**（Murch 六法则、《狂暴之路》十字准星构图）：切过去以后主体落在观众眼睛刚才所在的地方，多半在画面中央 ±15%。
5. **镜头跟平均路线**：横向只跟 30% 的蛇行，高度跟 75%，看的方向跟 70%——让角色在画面里动，而不是整个世界跟着晃。座舱镜头比心的闪避慢 0.1 s，只跟它横滚的一半倾斜。
6. **震屏只给真正的冲击**：砸地、碎裂、音爆、击落武装、受伤。变形的八声「咔」只留声音（锁定时一次震）；诱饵和浮游炮发射只轻震或不震；名牌六个字的砸落保留。
7. **HUD 是主观镜头**：先看见心在瞄他，再切进它的眼睛；整圈横滚只有一次；出 HUD 前地平线回正。
8. **新空间先交代**：第一个镜头看得见它的形状（峡谷两壁、光环隧道）和两人的位置。
9. **三维空间里只放三维的东西**：笼子、刀痕、阵形都要有厚度、有透视；用四分之三角度、慢慢环绕的镜头让人看得出前后。贴在画面上的平面图形只留给 HUD 或一个 16 分以内的提示。
10. **重复的乐句不重复分镜**；**每个镜头都要讲一件事**；**他不能挡住心**（光之翼和箱子差不多宽，冲刺时收翼）；**被分割出去的部分要和留下的一眼分开**。
11. **先看见，再挨打**：每次攻击至少一个八分音符的预兆（开火的那个东西本身发亮 + 整条路线的细线），开火有分量（宽、白芯、光晕、冲击波、后坐、收窄）；光束画满整个画面。
12. **他对着心时朝镜头侧转四分之三**（表演者面向观众），只在开炮一瞬对正；完全侧对时翅膀正对镜头会糊成一片白。

**打击的语法**：溜め（蓄，停在极端姿势上至少一个 16 分）→ 詰め（出手 ≤ 一个 16 分）→ 顿帧（画面停住，音乐不停）→ 冲击帧（黑白/反相）→ 读数（数字先 2 倍盖上去再落回原作大小）→ 留存。打在心上：心闪白、原作受伤音、HP 掉的那截先闪白再缩、画面泛红，三次一次比一次重。打掉武装：碎成像素 + 火花，他本人一动不动，世界替他动。
**速度的语法**：瞬间推进（位移压缩到 2–3 帧，起点推进器闪光、终点急停姿势）；每次推进 3–6 个粉/青错开的渐隐残像（TRANS-AM 变红变多）；网格/光环/数据雾真三维飞驰、尾迹留在世界里；甩镜按相机速度加运动模糊、结尾一个方向震动；顿帧与慢动作让快的地方更快。
**空战机位库**：追尾（心背后偏上）· HUD（第一人称）· 掠过（固定机位，多普勒呼啸）· 环绕慢动作（变形、眼镜蛇、命中）· 回望（被咬尾时）· 侧跟（剪刀、交错）· 俯视（浮游炮阵形）。**机动**全按真实飞行动作：横滚、侧滚、高 G 急转（翼尖白色蒸汽涡）、筋斗、半滚倒转 Split-S、眼镜蛇、剪刀、垂直爬升、螺旋。心在躲的时候，它和威胁它的东西必须都在画面里、看得清。
